SolutionSPA · DEMOSTRACIÓN TÉCNICA

Aviso de privacidad de la demostración

Esta versión de Solution SPA es una demostración técnica. No está configurada como operación comercial ni cuenta todavía con los datos legales de un responsable de tratamiento para recibir información personal real. Usa únicamente datos ficticios o de prueba.

Qué muestran los formularios

Los formularios públicos y de registro existen para demostrar flujos de solicitud, alta de cliente, agenda y gestión. Cuando el backend de pruebas está habilitado, la información enviada puede persistirse en una base de datos de demostración para validar el funcionamiento del sistema.

Uso permitido en esta demo

  • No envíes nombres, teléfonos, correos, contraseñas ni otros datos reales.
  • No envíes información médica, financiera, biométrica ni cualquier otro dato sensible.
  • Utiliza datos ficticios destinados exclusivamente a pruebas funcionales.

Requisito antes de producción

Antes de utilizar Solution SPA con clientes reales, la implementación deberá sustituir este aviso por uno específico del negocio que identifique al responsable legal, finalidades, datos tratados, base aplicable, conservación, transferencias cuando existan y un canal real para ejercer los derechos que correspondan. Ese cambio es un requisito de salida a producción, no una opción de diseño.
